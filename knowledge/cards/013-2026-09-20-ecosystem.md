## 二、协议与范式（对本项目影响最大）

1. **`AGENTS.md` 正在成为跨工具的通用约定。**
   Claude Code 已兼容：项目目录没有 `CLAUDE.md` 时自动读取 `AGENTS.md`，行为可在 `/config` 切换。
   `AGENTS.md` 最初源自 OpenAI Codex，被官方称为「面向 Agent 的 README」。
   有从业者指出：维护两份文件是「复杂性税」，**项目指令文件正从工具偏好变成代码库基础设施**。
   → **本项目待办**：W3 工作区能力应扩展为**自动读取工作区的 `AGENTS.md`** 作为项目级指令
   （与 W8 记忆模块的 blocks 合并，且要标明来源、可被用户查看/关闭）。

2. **Apple Safari 27 内置本地 MCP server**，把浏览器自动化暴露给 MCP 兼容 agent。
   → MCP 已是平台级标准（此前 Google Home MCP 亦为同一趋势），本项目 W10「不自造协议、直接接 MCP」的判断成立。

3. **插件供应链安全出问题**：出现 **Plugin4Shell 零点击 RCE**，影响主流编码 agent。
   并有**首个因 LLM agent 造成的数据泄露被监管立案**（西班牙 AEPD）。
   → 强烈印证本项目两条硬约束：
   - **样式包/插件只允许受控字段，拒绝任意 CSS/JS**（防 XSS/RCE）；
   - **权限按参数分级 + 敏感路径强制询问**（不靠模型自觉）。

4. **治理趋势：default-deny（默认拒绝）**。某 agent 框架的更新日志加入
   「default-deny governance guidance」与 `skills validate`（捕获静默的工具注册失败）。
   → 本项目 W5c「自定义权限规则表」应支持 **默认拒绝 + 白名单放行** 的写法，
   并对「工具名拼错/未注册」给出明确报错（我们已实现：未注册工具直接报错，不做模糊匹配）。

5. **Apple/Microsoft 生态动向**：Microsoft 正在整合 agent 框架（AutoGen 进入维护模式，
   Microsoft Agent Framework 成主路径）→ 提醒「框架依赖有供应商风险」，本项目坚持薄依赖 + 自持核心。
