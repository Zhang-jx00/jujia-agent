## 这个版本能做什么（能力面以 README 为准，这里只列主干）

- **对话与流式**：任意 OpenAI 兼容端点；停止、截断、上游断流三种结局在界面上分开说
- **改代码 / 管文件**：创建·修改·删除全部走审批；可"允许但先改参数"；改动前 diff 审阅
- **权限规则表**：`allow / deny / ask` + 工具名 glob + 按参数分级（同一个写文件工具，
  写普通文件与写 `.env` 结论不同）；deny 与高危清单在**任何放行模式下都生效**
- **路径沙箱**：`..` 逃逸、设备路径、UNC、NTFS 备用数据流、软链/junction 逃逸逐条拦住
- **内置终端**：真 PTY；每次新起会话**当面问一次**（不查规则表 —— 这一点在权限页明写）
- **内置浏览器 / 无限画布 / 轻量 IDE / 中文 PDF**：三档打开方式与外发硬确认；
  画布支持条件分支与有界循环；中文 PDF 走内联 cmap，全程可零出站
- **MCP 工具接入**：连接同意界面逐字展示要执行的命令；未批准的工具**没有调用路径**；
  "只读"这一档**是服务端自己声明的**，批准界面上就这么写（见"已知边界"）
- **执行审计**：每次判定落一行账（结论 / 理由 / 做没做成），参数只记键名 + 长度 + 指纹，
  **正文与密钥不进账本**，导出的是同一本账不做第二次加工
- **长任务与断点续跑**：崩溃后说得出"断在第几步"；续跑**重新过审批门**、不回放任何动作
- **定时任务 · 结构化日志 · 检查更新**：定时到点**不等于免审批**；日志落盘前先剔密；
  更新只查一次说一句，**自动下载刻意不开**

## 已知边界（这一节是本项目最不肯省略的地方）

- **命令前缀规则仍有两类形态管不到**：`deny git push` 现在拦得住 `git.exe push` / `"git" push` /
  绝对路径形态（R47 收紧，比的是「程序名 + 参数」两段），但**参数插在中间**（`git -C x push`）与
  **套一层 shell**（`cmd /c git push`）仍会漏 —— 前缀证明不了整条命令做什么。规则页已把这条说出口。
- **MCP 工具"只读"是服务端自述的**：走到这一档不再问你；而工具参数是任意 JSON，
  本机敏感路径表只认 `path` 这一个键 —— 所以"外部服务自称只读就能读走任意文件"是**真实可达**的状态。
  批准界面已经把这句话摆在台面上（R47 还多说了"本机不替它担保"）；**这一档的判定本轮没动**
  （信任边界不移动 —— 改它仍属要另行拍板的那一类）。
- **未签名**：个人项目的构建没有代码签名证书，首次运行会被 SmartScreen 拦（需要「更多信息 → 仍要运行」）。
- **只支持 Windows**；macOS / Linux 未验证。
- 多模态只到**图片输入**（且附件不落盘、图片会随请求发给所配服务商 —— 发送前界面上明说）；
  媒体生成未做。子代理 / 远程接入未做。

## 隐私与安全承诺

配置、会话、日志、审计账全在本机；密钥走系统加密存储，**不进渲染层、不进模型上下文、不进聊天文本、不进提交**。
数据默认不出本机（唯一的例外是你显式接入自己的主机）；出本机的地方**逐条列在 `SECURITY.md` 的出站表里**（模型请求 / 图片附件 / 绘图生成 / 更新检查 / 内置浏览器 / 你自己批准的 MCP 服务端）；其中模型请求、图片附件、绘图生成、更新检查在界面上都是一次动作对应一句说明。
发现问题请按 `.github/ISSUE_TEMPLATE` 里的私密渠道说明，别开公开 issue。
