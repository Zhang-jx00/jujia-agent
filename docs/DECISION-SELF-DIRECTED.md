**仍然不做的两条**（**不是"没人拍板"的问题，是动作本身不可逆且对外可见**）：
1. **把仓库切公开 / 发版 / 更新发布页** ⇒ 只做到「**公开前置检查单逐条做完并留证据**」
   （`docs/HANDOVER.md` §5.9 的清单），最后那一下**等一句明确的「发」**。
2. **凭据轮换** ⇒ 需要 GCM 浏览器交互授权链，**非交互环境做不了**；
   只做到「查清现役凭据状态 + 写清轮换步骤」（现役 = OAuth 令牌，轮换步骤见 `docs/HANDOVER.md` §5.9）。

> **自主 ≠ 降标准**：每轮仍走全套纪律 ——
> **先复核 → 动手 → 两遍复核 → 台账 → 门禁全绿 → 提交 → 打标签 → 推送 → 记账**；
> **不因"没人拍板"就跳过门禁、缩小范围、或把判据放宽**。

## 三、写给自己的三条约束

1. **决定要留痕**：每一项决定都进本文件 + 对应的 ROADMAP 行 / `DESIGN-BASELINE.md` 的 Known Gaps
   ⇒ **不许变成"我说了算"的口头结论**；将来要改，也得改同样的地方。
2. **不许因为"没人拍板"就降标准**：门禁全绿、能红校准、e2e 真跑、变异有据 —— 与有人拍板时**一模一样**。
3. **幻觉零容忍**：数字 / 哈希 / 时刻 / 版本归属**只从真实命令输出抄**；写进文档的引用**逐条核**；
   探针给出的**结论**（不只是报错）要被第二种方法交叉核对 —— 否则就是把探针的错误写进台账。
