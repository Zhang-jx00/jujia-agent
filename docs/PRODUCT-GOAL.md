# 俱佳Agent · 产品最终目标

> **文档性质**：这是「做完之后长什么样」的最终定义，是 PLAN（怎么做）的上游。
> 与 PLAN 冲突时以本文为准，并回头修正 PLAN。
> **最近核实**：2026-09-18（含 2026-09-16/17 的行业动态，来源见 §7）

---

## 1. 一句话定位

**一个跑在你自己 Windows 电脑上的个人 Agent**：它能读你的文件、改你的代码、跑你的命令，
但**每一步有副作用的动作都要你点头**，而且**所有数据默认不出本机**。

不是「又一个聊天框」，也不是「云端的持久化工作流平台」。

---

## 2. 最终形态：做完之后你能做什么

### 2.1 核心场景（每条都是可验收的）

| # | 场景 | 判定标准 |
|---|------|----------|
| S1 | 在指定工作区里对话式改代码 | 让它「新建 hello.md 并写入内容」，文件真的出现，内容正确，权限面板正常弹出且可拒绝 |
| S2 | 读懂现有项目再动手 | 问「这个项目的入口在哪、怎么构建」，它能读文件后给出带**文件路径引用**的答案 |
| S3 | 越界尝试必须被拦住 | 一旦它试图写 `C:\Windows\...` 或 `..\..\`，**操作被拒且有中文提示**，磁盘未被改动 |
| S4 | 高危操作必须人工确认 | 删除、覆盖敏感文件（`.env`、`.git/`、私钥）**一律弹出审批**，即使已开自动模式 |
| S5 | 长任务可中断可续 | 生成中随时能停；停掉后已产出的内容保留，不被清空 |
| S6 | 换模型不用改代码 | 在「连接」页填 base URL + Key（或改成本地 Ollama），即可切换；点「测试」能列出该端点真实可用模型 |
| S7 | 无限画布编排工作流（P4） | 拖拽建节点（提示词/工具/子代理）、连线、右键菜单；节点上千仍能平移不卡；成环被拒 |
| S8 | 内置浏览器可当工具用（P5） | Agent 能打开网页、取正文、截图作为上下文；危险 scheme 与弹窗一律拒绝 |
| S9 | 多模态按能力门控（P5） | 未配置具备该能力的模型时，对应入口**禁用并说明原因**，而不是点了报错 |
| S10 | 全程可回溯 | 每次工具调用都有记录（工具名/参数/结果/耗时/是否被批准）；配置损坏能自愈且明确告知 |

### 2.2 体验上的硬要求

- **流式不卡**：生成期间输入框始终可用，随时能停
- **错误说人话**：区分「密钥错 / 超时 / 网络不可达 / 上游结构异常」，并给下一步建议
- **不假装成功**：内容被截断要标注；工具失败要把错误告诉模型让它改，而不是静默吞掉
- **永不静默自动拒绝**：默认模式下不替用户拒绝，而是问；「拒绝而不问」是用户显式选择的模式
- **数据默认本地**：配置、连接、会话、日志都在本机；密钥用系统凭据能力加密

## 3. 明确不做什么（非目标）

| 不做 | 原因 |
|------|------|
| 云端持久化多线程工作流平台 | 2026 年主流路线是「一个对话 → 多个云线程、离开后继续跑」（Claude Code Projects / Cursor Projects）；本项目**刻意选本地单机路线**，换取隐私与零订阅 |
| 团队协作 / 权限角色 / 审计合规套件 | 个人学习项目，不承担企业合规 |
| 自建模型 / 训练 | 只做编排与工具层 |
| 移动端 / 网页版 | 只做 Windows 桌面 |
| 「替代 IDE」 | 定位是 Agent，不是编辑器；不做完整 IDE 功能 |

## 4. 与 2026 年主流路线的取舍（为什么这样选）

核实到的新范式与本项目的取舍（来源见 §7）：

| 新范式（2026） | 本项目做法 | 理由 |
|---------------|-----------|------|
| 云侧持久化 + 异步默认（Claude Code Projects / Cursor Projects） | **本地单机 + 会话可续** | 隐私优先；不引入云成本与账号依赖 |
| Google Credentials API：**用占位符把密钥挡在模型上下文外** | 已做「密钥不进渲染层」，**待补：密钥不进模型上下文**（发给模型的消息里不含密钥） | 同一安全目标，分步落地 |
| **MCP 已成事实标准**（Google Home MCP 等） | P3/P4 阶段接入 **MCP 客户端**（而非自造插件协议） | 不自创协议，直接复用生态 |
| Grok Bot + 1Password：**凭据托管、每次填充都要批准** | 现方案：API Key 用系统加密存储；**待补**：与系统凭据管理器集成 | 暂不引入第三方密码管理器依赖 |
| LLM-as-judge / 分类器优先（"AI if statement"） | 权限分级用**确定性规则**（非模型判断） | 安全判定不能交给概率模型 |
| 激进压缩对话历史以省 token | **不采用**：核实显示激进压缩会损坏隐藏推理与缓存前缀 | 宁可多花 token，也不牺牲长程能力 |

## 5. 验收：产品「做完了」的判定

以下**全部满足**才算完成（对齐 PLAN 的 M1–M5b）：

1. **M1 能对话**：配好连接即可流式对话，可停、可换模型（✅ 已完成）
2. **M2 能改代码**：能创建 `hello.md`；权限面板正确出现、不闪退、可拒绝（🔶 权限策略已就绪，**对话页接线待做**）
3. **M3 能查资料**：内置浏览器取正文/截图入上下文
4. **M4 能编排**：无限画布上搭出「输入 → LLM → 工具 → 输出」并跑通
5. **M5 能扩展**：MCP / Skills / Hooks 可用，能力门控正确
6. **工程底线**：`typecheck / lint / test / smoke` 四件套全绿；打包后**换一台干净 Windows 能装上并跑通**

## 7. 已知限制与风险（如实记录）

| 限制 | 影响 | 现状 |
|------|------|------|
| 本机网络对 `api.openai.com` 不可达（实测 000） | 无法直连 OpenAI | 已如实提示；换代理即可用 |
| 审批暂停是**进程内**的（120s 超时） | 若人工长时间不响应或应用重启，待批请求会丢 | 已记为待办；需评估是否要持久化 |
| 测试目前不覆盖真实厂商 API 调用 | 真机联调需用户自己的 Key | 用本地 mock SSE 服务覆盖了协议路径 |
| MCP / 内置浏览器 / 画布尚未开始 | 三大块工作量集中在后半程 | 按 PLAN 推进 |
