## 五、给下一步开发的三条建议

1. **先做 capability registry，再做视频生成**：R10 的正确实现顺序是「能力声明 → UI 禁用/降级 → 探测失败兜底」，倒过来做会出现「按钮点了才报错」。
2. **画布选型建议直接基于 React Flow（xyflow）**：#86–94 的对标结论显示，其 viewport/Handle/isValidConnection API 与用户三项硬需求一一对应，自研画布放后期。
3. **把 SOURCE-MATRIX 当验收工具用**：每周开发前查对应簇的来源（官方文档怎么定、竞品源码怎么写、社区踩过什么坑），比现搜更省时间。
