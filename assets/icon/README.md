**制作方式**：源图的图形与构图**完全保留**，仅做**黑白单色化**。
具体做法是**只替换 RGB、原样保留 alpha 通道** —— **不做阈值化、不做重采样、不做矢量化**，
因此形状一个像素都没有变。

**该性质由脚本自检保证**（不是靠人眼）：`node apps/desktop/scripts/make-logo-mono.mjs <源图>`
会逐字节比对输出的 alpha 与输入 alpha，一旦不一致立即报错退出。
实测结果：**122100 个像素的 alpha 全部一致** ✓

## 它长什么样 / 为什么这样设计

深色圆角底 + 居中的蓝色**盾牌与宝石**复合图形 + 两点星光。

- **盾牌** → 这个项目的核心承诺：**每个有副作用的动作都要你点头**
- **宝石** → 取自项目名「俱佳」（"佳"即好、珍贵）
- **深色圆角底** → 与应用的暗色主题一致；小尺寸下仍是清晰的方形轮廓

**刻意不放任何文字**：一是避免字体商用许可问题，二是避免小尺寸下的字符错误

### 关于 AI 生成图像的版权（如实说明，不回避）

2026 年的现状是**法律上未定论**，我们按已核实的公开信息如实记录：

- **美国版权局立场**：纯粹机器生成、无实质人类创作的内容**不受版权保护**；
  人类的选择、编排与实质性编辑**可以**受保护
  （*Zarya of the Dawn* 案：人类撰写的文字与页面的选择编排获准登记，AI 生成的图像被排除；
  *Thaler v. Perlmutter* 进一步确认"无人类作者的自主生成作品"无法登记）
- **推论（对我们的影响）**：AI 生成的图标**你可以自由使用，别人也可以自由复制**。
  对一个 **MIT 开源项目**来说这**不构成问题** —— 我们本来就放弃了独占
- **我们避开的坑**：
  - 图内**不含文字** → 不涉及字体商用许可
  - **保留 prompt 与处理脚本** → 作为"人类参与"的证据链（`make-icon.mjs` + 本文件）
  - **不模仿已知品牌** → 降低商标风险（若你发现它与某品牌过于相似，请开 issue，我们会更换）

> 如果你要在**闭源/商业**场景使用并需要独占性，建议自行替换为你有权独占的图标。
